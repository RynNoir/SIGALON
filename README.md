# SIGALON — Paket Dokumentasi Kerja

Mulai di sini:
1. `CLAUDE.md` — instruksi utama AI coding.
2. `docs/PRD.md` — kebutuhan produk dan aturan bisnis.
3. `docs/ERD_SIGALON.md` — model data (6 tabel inti) dan aturan status.
4. `docs/sprints/sprint-1.md` sampai `sprint-4.md` — isi form J-01 per sprint (goal, backlog, task, kesepakatan) beserta catatan rekonsiliasi dengan kode.
5. `docs/USER_STORIES_STATUS.md` — status story dan bukti.
6. `docs/DEVELOPMENT_WORKFLOW.md` — alur kerja tim lima orang.
7. `docs/DESIGN_SYSTEM.md` — pedoman UI/UX dan token warna.
8. `docs/design/README.md` — referensi visual per layar (apa yang diambil dan apa yang tidak).
9. `AGENTS.md` — instruksi umum untuk AI coding agent lain.

## Catatan
- Dokumen ini adalah starter pack; salin ke root repository dan sesuaikan setelah direview tim.
- Backlog Sprint 1–4 sudah direkonsiliasi dengan J-01 (PRD v1.2 §12).
- Tidak ada status implementasi yang diklaim selesai karena repository kode belum diperiksa.
- AI tidak boleh melakukan commit/push otomatis; hanya menyarankan pesan commit.
